# 本地底图

这些文件由 Natural Earth 公共领域数据裁切、简化后得到，只覆盖长征涉及的经纬度窗口。条款摘录在 `NATURAL-EARTH-TERMS.txt`。页面上写 “Made with Natural Earth”。原始 zip 不放进仓库。

- `land.json`：50m 陆地，裁到窗口里。
- `rivers.json`：10m 具名河网中的长江、金沙江、湘江、乌江、大渡河、岷江、嘉陵江、黄河等。精度只够认方位，不能当战场线。赤水河不在这份具名河网里，所以没有编一条河。
- `provinces.json`：50m 当代中国一级政区。这是今行政区划，不是 1934–1936 年省界。西康等民国省界没有取得可再分发的文件，因此不画。
- `places.json`：30 个 Wikidata P625 近似坐标。`geometry_level` 标明是遗址、镇、县城还是山体。县城坐标不能当成渡口。

投影在页面里用阿尔伯斯等积圆锥（标准纬线 25°、40°，中央经线 105°E）。虚线只连接相距较近、且先后关系清楚的已知点。
