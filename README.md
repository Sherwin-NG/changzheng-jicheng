# 长征纪程

一九三四年十月至一九三六年十月，中央红军、红二十五军、红四方面军，以及红二、红六军团（后为红二方面军）的中文阅读专题。页面按核链稿写成，来源可以点开。它是独立整理，不是博物馆、档案馆或党史机构的展览。

路线图是分路节点示意，不是测绘轨迹。站点不使用历史照片。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm ci
npm run dev
```

开发服务器在 <http://127.0.0.1:43123>。

```bash
npm run check
npm run build
npm run preview
```

`npm run build` 会先检查来源编号，再做类型检查，然后把静态文件写到 `dist/`。生产构建使用相对路径，所以同一份 `dist` 可以放在域名根目录，也可以放在 `/仓库名/` 下面。

## 部署到 GitHub Pages

本仓库只准备好了可以部署的源码和工作流，没有代为创建公开网站。

1. 把这个目录推到你自己的 GitHub 仓库。
2. 打开仓库的 Settings → Pages，Source 选 GitHub Actions。
3. `.github/workflows/pages.yml` 会在推送到 `main` 或 `master` 时构建并部署。也可以手动运行 Deploy GitHub Pages。
4. 用户站点（`username.github.io`）和项目站点（`username.github.io/仓库名/`）用的是同一次构建。不要把 Vite 的 `base` 改成仓库名，否则根路径部署会找不到样式。
5. 打开页面时地址最好以 `/` 或具体的 `.html` 结尾。相对路径是按当前文件解析的。

刷新已经存在的页面不会 404，因为每一章都是真实的 HTML 文件。没有数据库，也没有登录。

## 内容从哪里来

`content/research-main.md` 是核链主文。`content/data/` 里是来源、年表、四路、会议、战役、人物、节点和口径。页面上的事实都回到这些文件，并链到对应机构的标题和 URL。

核链稿记录的查阅日是查阅日，不是历史文献的出版日，也不是本站的新闻发表日。出版日写在各条来源上。

红四方面军的 3 月说和 5 月说、红二方面军的 8 省和 9 省、出发人数的不同细数，都并列保留，不收成一个数字。

## 地图

`routes.html` 的图完全在本地 SVG 里，不请求地图瓦片，也不使用需要密钥的接口。图上的免责声明不能关掉。横轴是阅读顺序，不是东西方向。

标题使用随仓库分发的 Noto Serif SC，正文使用 Noto Sans SC。字体采用 SIL Open Font License，许可证全文在 `public/fonts/OFL.txt`。

## 无障碍

可以只用键盘：`/` 打开检索，`Esc` 关闭，方向键在检索结果和年表按钮之间移动。焦点有可见轮廓。系统开启“减少动态效果”后，页面不再做动画。

## 当前边界

- 不收录未授权的历史照片。
- 不补泸定桥突击队尚未核全的姓名。
- 西路军只作为会师之后的边界说明，不放进长征结束之前的年表。
- 个别人民网党史页在部分网络环境下握手失败。页面写明这不是 404。
